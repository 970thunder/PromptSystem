## 当前页面与路由

| 路由 | 视图 | 说明 |
|---|---|---|
| `/` | `HomeView.vue` | 产品式首页：hero + 搜索 + 标题飘带 + 今日精选（1 主卡 + 2 小卡）+ 最新发布网格 + 分类/标签 + 发布引导 |
| `/search` | `SearchView.vue` | 发现/搜索：keyword/tag/categoryId/model/sort 均走 URL 恢复 |
| `/prompt/:id` | `PromptDetailView.vue` | 详情：结构化区块、复制、点赞/收藏/评论/举报、相关推荐、返回上下文 |
| `/publish` | `PublishView.vue` | 五步发布向导（封面/基本信息/提示词/参数与标签/确认），需登录 |
| `/profile` | `ProfileView.vue` | 本人工作台：资料、内容库七页签，需登录 |
| `/profile/:userId` | `ProfileView.vue` | 公开作者页，可匿名访问 |
| `/community` | `CommunityView.vue` | 社区页：工作流/智能体/最新动态 |
| `/login` `/register` `/forgot-password` | 认证三页 | 验证码/邮箱能力受 `siteCapabilities` 开关控制 |
| `/auth/callback` | `AuthCallbackView.vue` | GitHub OAuth 回调（能力开关） |

## 外壳与全局组件

- `AppShell.vue` = SiteHeader（下推式 MegaMenu）+ main + 页脚；所有视图共用，无 View 内重复 Header。
- 反馈组件：`PageLoading`（blocks/grid 变体）、`PageError`（error/empty、`busy`、重试动作）。
- 卡片体系：`PromptCard`（gallery/result/compact）+ `PromptGrid`（加载/空/到底/加载更多）。

## 可用 API/Store 边界

- `request.ts`：axios + HttpOnly Cookie 会话 + `X-CSRF-Token` 双提交 + 401 统一处理；Bearer 仅兼容保留。
- `stores/prompt.ts`：信息流/详情/评论统一 loading/error/empty；AbortController + 请求序号防竞态；API 关闭时走 `mock/prompts.ts`（仅开发/测试）。
- `stores/user.ts`：`restoreSession/fetchUserInfo` 会话恢复，`sessionActive` 单一事实来源。
- 契约：`docs/api-contract.schema.json` + `npm run contract:check`。

## 主题

- `tokens.css` 在 `html[data-mode]` 上定义 light/dark 全套令牌；`useSiteTheme` 负责初始化、system 监听与 View Transitions 圆环扩散；`prefers-reduced-motion` 全分支支持。
